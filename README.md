# 🎬 Kids Learning - YouTube Shorts Video Studio

An all-in-one, browser-based **YouTube Shorts & TikTok Video Generator** designed specifically for creating high-retention educational kids content. Built entirely with vanilla HTML5, Canvas 2D, Web Audio API, and MediaRecorder API — runs 100% locally and offline with zero external dependencies.

---

## ✨ Features

- **🎯 10+ Interactive Learning Categories:**
  - 🚩 **Country Flags:** Procedural vector flag engine supporting all 195+ world countries (Nordic crosses, tricolors, serrated flags, stars, crescents, cantons) + Explorer with regional presets and autocomplete search.
  - 🧍 **Human Body Parts (3D Anatomy):** Dual-view (Front / Back) full anatomy model with targeted pulse markers and labels.
  - 🐟 **Fish & Sea Creatures:** High-definition vector graphics and guessing quiz for Goldfish, Clownfish, Shark, Dolphin, Pufferfish, Blue Tang, Catfish, and marine life.
  - 🦁 **Animals & Birds:** Rich procedural graphics for domestic & wild animals.
  - 🥦 **Healthy Vegetables:** High-definition vector graphics and guessing quiz for Carrot, Broccoli, Tomato, Potato, Corn, Eggplant, Pumpkin, and fresh garden vegetables.
  - 🍎 **Fresh Fruits:** Colorful, child-friendly illustrations and quizzes.
  - 🔷 **Geometric Shapes:** High-definition vector graphics and guessing quiz for Circle, Square, Triangle, Star, Heart, Diamond, Hexagon, Crescent, Oval, Rectangle with cute cartoon eyes.
  - 🎒 **Everyday Items:** High-definition vector graphics and guessing quiz for Clock, Pencil, Cup, Book, Umbrella, Backpack, Scissors, Glasses, Phone, Key, Toothbrush, Water Bottle.
  - 🚗 **Vehicles & Transport:** High-definition vector graphics and guessing quiz for Car, Bus, Airplane, Train, Bicycle, Helicopter, Ship, Rocket with animated details.
  - 🎨 **Colors & Rainbow:** High-definition glossy paint splat vector graphics and guessing quiz for Red, Blue, Green, Yellow, Orange, Purple, Pink, Rainbow, Gold, etc.
  - 🌸 **Flowers & Plants:** Engaging visual quizzes.

- **⏱️ High-Retention Fast-Paced Format:**
  - **Quick Hook Question:** Pops up within the first second with sound effects.
  - **5-Second Countdown Timer:** Clean animated circular countdown accompanied by tension-building background music.
  - **Celebration Reveal:** Confetti explosion, celebratory sound effect, and voice narration when the countdown ends.
  - **Seamless Loop:** Visuals and audio engineered to loop naturally, maximizing viewer retention (>100% completion rate).

- **🎵 Synthesized Audio & Music Engine:**
  - Real-time procedural sound effects (pops, tick-tocks, fanfare, applause) generated dynamically via Web Audio API.
  - Royalty-free suspense background music playing during the guessing countdown.
  - Text-to-Speech (TTS) integration with natural voice pronunciation for questions and answers.

- **📹 High-Definition Video Export:**
  - Records directly in standard **1080 × 1920 (9:16 vertical Shorts format)**.
  - Seamlessly combines visual animations and synthesized audio into a downloadable `.webm` video file.
  - Ready for direct upload to YouTube Shorts, Instagram Reels, and TikTok.

## 🚀 How to Use

1. **Clone or Download:**
   ```bash
   git clone https://github.com/omithhasantanvir/Kids-Learning.git
   cd Kids-Learning
   ```

2. **Open in Browser:**
   - Simply double-click `index.html` or open it in Google Chrome / any modern web browser.
   - No server, build step, or npm install required!

3. **Generate Video:**
   - Select your desired **Category** (e.g. *Country Flags*, *Human Body Parts*, etc.).
   - Pick or customize the list of items / countries.
   - Click **▶ Preview** to review the animation and sound in real time.
   - Click **🔴 Record & Download (With Sound)** to render and download your ready-to-publish video!

## 🛠️ Tech Stack

- **HTML5 Canvas 2D** – Procedural vector rendering & animation
- **Web Audio API** – Pure synthesized sound effects & background music
- **Web Speech Synthesis API** – Text-to-speech voiceovers
- **MediaStream Recording API** – Canvas + Audio capture to WebM
